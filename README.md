# Save & Serve

Aplicación web desarrollada como Trabajo de **Fin de Curso**, cuyo objetivo es reducir el desperdicio alimentario conectando establecimientos que desean donar alimentos con usuarios u organizaciones que pueden recogerlos.
El proyecto permite a los comercios publicar alimentos disponibles y decidir qué ONG o banco de alimentos puede recogerlos, facilitando una gestión eficiente de donaciones.

El proyecto está dividido en:

- Frontend: IONIC
- Backend: Spring Boot
- Base de datos: (MySQL)

## Tecnologías utilizadas

**Frontend**
- Ionic Framework
- HTML5, CSS3, SCSS
- Capacitor
- Responsive design para web y móvil
    
**Backend**
- Spring Boot
- Spring Data JPA / Hibernate
- Spring Security 
- API REST
        
**Base de datos**
- MySQL

## Funcionalidades principales

- Registro e inicio de sesión para usuarios, comercios y administradores.
- Los comercios pueden subir alimentos disponibles para donar.
- Los comercios pueden asignar los alimentos a ONGs o bancos de alimentos específicos.
- Administrador puede crear y gestionar artículos informativos sobre desperdicio alimentario.
- Listado y gestión de alimentos disponibles.
- Gestión de usuarios y roles.
- Interfaz responsive y usable en dispositivos móviles.
